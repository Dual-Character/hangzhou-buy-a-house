# 杭州买房调研

个人**杭州买房**决策工作区：购房预算与硬性条件、候选小区调研、板块与市场行情、决策记录。

不是一个代码仓库——没有构建、测试和依赖。这里唯一的产出物是**可复查的结论文档**，不是代码。

## 目录结构

```
AGENTS.md            工作区规则：调研标准清单、来源纪律、分析纪律
templates/           小区调研模板（新小区一律按此模板产出）
communities/         单个小区调研，一小区一文件
decisions/           购房条件、候选对比、决策记录
```

## 调研口径

- **只认官方来源**：学区按教育局当年划分公告，参数按政府公示/土拍公告，房产聚合站仅作参考并标注「待核」
- **严格区分挂牌价与成交价**，不混用
- **每条数据带来源 + 采集日期**，没有来源的数字不写进文档
- **口径矛盾保留矛盾**，不自选一个当结论，单列矛盾对照表
- **结论先行**：买不买、坑在哪，先给判断再给理由
- 每个小区文档结尾必须有「待核实」清单

## 说明

个人研究记录，内容来自公开渠道检索，部分数据未经实地核验。仅供自己决策参考，不构成任何购房建议。
